The AI · Microsoft Foundry

Five agents, one job each

Moment Analyst

Reads each fan photo or clip: what happened, how sure it is, and whether it matters for safety.

Moment Matcher

Same match, same kind of event, close in time: groups clips as angles of one Moment.

Highlight Curator

Ranks a Moment’s angles so the best one fronts it.

Storyteller

Writes the title and summary fans see, using the live match context.

Safety Analyst

Triages every SOS report, refining the instant rule-based severity.

People decide

AI drafts; a moderator publishes. If AI is off, rules keep Roar running.

Each agent is one structured model call on Microsoft Foundry (Azure OpenAI deployment gpt-5-mini).

Each agent does one thing with its own prompt and output schema. The Analyst reads the media, the Matcher groups angles, the Curator ranks them, the Storyteller writes the copy, and the Safety Analyst triages SOS reports. Nothing goes public on AI’s say-so: a moderator publishes. If no AI provider is configured, every agent returns nothing and Roar falls back to its rules.
