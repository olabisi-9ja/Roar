Everything runs on Azure today. Phones, glasses and the control room talk to the Roar API on Azure Container Apps, alongside the fan web app and the control room console. The API calls our agents on Microsoft Foundry, stores data in Azure Database for PostgreSQL, and keeps clips in a private Blob container that it reaches with a managed identity, so there is no storage key anywhere.
